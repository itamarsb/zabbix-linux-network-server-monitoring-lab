This register captures possible documentation inconsistencies identified while preparing Portuguese translations. It is separate from the translated documents and from validated laboratory evidence.

**Scope reviewed:** main `README.md`, full Stage 00–07 documentation (`labs/00-workstation-validation/README.md`, `labs/01-zabbix-platform/README.md`, `labs/02-linux-host-monitoring/README.md`, `labs/03-windows-host-monitoring/README.md`, `labs/04-network-service-monitoring/README.md`, `labs/05-triggers-alert-handling/README.md`, `labs/06-alert-delivery-notifications/README.md`, `labs/07-maintenance-operational-reporting/README.md`), Stage 07 maintenance and handover records, the Stage 00 validation script (`scripts/powershell/validate-workstation.ps1`), current `compose.yaml`, `.env.example`, and completed-stage summaries.

**Review date:** 2026-11-04 (updated through Stage 07)

**Review status:** findings recorded for later technical verification; no corrective changes made to the original English documentation.
